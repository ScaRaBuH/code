Cистема анализа документов

Интеллектуальная система для автоматизированного сбора, структурирования и анализа многостраничных статистических документов с использованием локальных больших языковых моделей (LLM).


🚀 О проекте

Проект решает проблему анализа больших документов, которые содержат сложные иерархические таблицы. Система переводит визуальный PDF в структурированный Markdown формат и позволяет вести диалог с документом на естественном языке, используя архитектуру RAG (Retrieval-Augmented Generation).


🛠 Технологический стек

Парсинг: Docling (использование нейросетевых моделей для восстановления структуры таблиц).

LLM: Qwen 2.5 (14b) – запуск через Ollama.

Интерфейс: Streamlit – веб-оболочка для управления документами и чата.

База данных: SQLite (хранение полнотекстовой разметки и метаданных).

Аппаратное ускорение: AMD ROCm.


⚙️ Ключевые особенности

Layout-Aware Parsing: В отличие от классических методов, система понимает границы таблиц и логику ячеек, сохраняя их в Markdown формате.

Динамический поиск контекста: Реализован алгоритм «умного окна», который находит релевантный фрагмент в БД и передает модели только нужный срез.

Конфиденциальность: Все вычисления проходят локально. Данные не отправляются в облачные API.

Оптимизация под AMD: Интеграция библиотек ROCm для ускорения работы Ollama.


📁 Структура проекта

 app.py – Главный файл интерфейса Streamlit.

 docling_parser.py – Модуль сегментированного парсинга PDF-документов.

 analyzer.py – Логика взаимодействия с LLM и алгоритм поиска контекста.


📦 Установка и запуск

  Клонирование репозитория:
  
  git clone https://github.com/ScaRaBuH/code.git
  
  cd code

  Настройка окружения:
  
  pip install -r requirements.txt

  Запуск Ollama:
  
  Убедитесь, что Ollama запущена и модель загружена:
  
  ollama run qwen2.5:14b

  Запуск приложения через консоль:
  
  streamlit run app.py 

  Запуск приложения через файл:

  start_analyzer.bat
